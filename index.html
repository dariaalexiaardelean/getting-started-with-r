Getting started with R

Extra practice for Statistics for Brain and Cognitive Sciences — CN2, 2026/27

ImportantThis is not the course material

The course is taught from Prof. Noventa’s lectures and his R scripts, which are on Moodle. Those are what you are assessed on.

This site is optional. It exists for one reason: if you have never used R before, the first thing you meet in this course is a script that opens with library() and a model fit on line 1. These four practicals are the part nobody teaches — enough R that those scripts become readable.

If you already use R, you can skip all of it.

What is here

Four practicals. The first three run alongside the Introduction to R lectures, one each, covering the same ground more slowly and with exercises. The fourth covers something the lectures do not: handling and plotting data, which every analysis script in the course quietly assumes you can already do.

# Practical Alongside What it covers
01 Basics of R Introduction to R, Part 1 calculator, objects, help, workspace, reading data
02 R objects, attributes, matrices Introduction to R, Part 2 types, vectors, subsetting, recycling, NA, factors, matrices
03 Lists, data frames, control flow, functions Introduction to R, Part 3 lists, data frames, tibbles, if/for, writing functions
04 Working with data, and drawing it — subsetting, recoding, summaries, base graphics, wide ↔︎ long

Each practical also has an appendix — optional asides for anyone who wants to know why something works. Nothing in an appendix is needed for anything else.

The material stops where the statistics begins. Regression and everything after it is the course’s own, and Prof. Noventa’s scripts are where you should learn it.

Two ways to use it

You can read it in the browser — every practical is a page on this site, with all the code and its output already shown.

Or you can download it and run it, which is the point. Each practical has a download link at the top of its page, giving you a zip containing:

  • the .R script for that practical,
  • a data/ folder with the data and a codebook explaining every variable,
  • an .Rproj file.

Unzip it, then double-click the .Rproj before opening the script. That sets R’s working directory for you, which is why none of these scripts contain a setwd() line.

The page and the script contain exactly the same material — they are generated from one source, so they cannot disagree.

Solutions

Every exercise has a worked solution, and they are not shown at first. Each practical’s answers appear on this site after that practical has been covered in class. Try the exercise first; the answer is worth much more once you have been stuck on it.

Before you start

Work through Setting up R — install R, RStudio, and the four packages the practicals use. Do that before anything else, not while you are trying to follow a practical.

TipOne habit worth forming now

Run code one line at a time with Ctrl+Enter (Cmd+Enter on a Mac), and read what each line prints. Do not press Source — the exercises contain ___ blanks for you to fill in, and Source tries to parse the whole file at once, so a single unfilled blank stops everything before any of it runs.
